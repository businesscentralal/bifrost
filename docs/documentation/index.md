# Guides

Setting Bifröst up is in [Set it up](/setup/). This part is for what comes after: using it, running
it, connecting to it and building on it. Start with the page for your role.

## If Business Central is yours

| You are … | Read | For |
|---|---|---|
| **A user** | [Users](/documentation/end-customers/users/) | What you can ask, what it will not do, and what to do when it says no |
| **An administrator** | [Administrators](/documentation/end-customers/administrators/) | Permissions, what agents may see, logs, usage, and what you are responsible for |
| **A developer** | [Developers](/documentation/end-customers/developers/) | Connecting another system, driving it from an agent, and the reference |

## If you work with other companies' Business Central

| You are … | Read |
|---|---|
| **A partner or reseller**, setting up and supporting Bifröst for customers | [Partners and ISVs](/documentation/partners/) |
| **An ISV or developer** building an app on Bifröst | [Partners and ISVs](/documentation/partners/), then [Build on Bifröst](/extensibility/) |

## For everyone

[How Bifröst works](/documentation/how-it-works/) explains the ideas once: message types, the one gate every call
goes through, and how an agent finds and calls the right operation.
