Bifrost Attachments connects Business Central file operations and attachments to registered storage accounts. Administrators set up a connection to an account managed by a Business Central storage connector.

Open **Bifrost Setup**, choose **Attachments**, and follow the [setup help](/help/attachments/attachments-setup/). Review the account, base path and enabled state before using a connection.

Use the setup page to manage file accounts and storage connections, or to remove abandoned upload sessions.
