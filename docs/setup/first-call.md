# Step 5: Make the first call

**Who is needed:** The administrator, then each user.

1. **Check the setup.** Bifrost Setup opens without a setup notification at the top, and every caller has
   the permissions from [step 2](/setup/business-central/#give-people-and-apps-permission), with
   only the posting gates it needs.
2. **Ask one question.** In a connected assistant, ask *"Who am I in Business Central?"*. The call
   appears on **Bifrost Messages**, with the user you expected as the caller.
3. **Try something real.** [Try it out](/try-it-out/) has prompts to start with, from a simple
   question to a change you preview first.
4. **Let your users connect.** Each user adds Bifröst to their assistant as in
   [step 3](/setup/connect-your-ai/#add-bifröst-to-the-assistant), and signs in as themselves.
   Send them [Using Bifröst](/documentation/end-customers/users/): what they can ask, what it will
   not do, and what to do when it says no.

That is the setup done. From here on, see
[Documentation for administrators](/documentation/end-customers/administrators/).
