# Support

## Documentation

Everything published about the Bifröst apps lives on
<https://bifrost.origo.is> — product documentation, in-product help,
extensibility guidance and skills for AI agents.

## Getting help

| What you need | Where to go |
| --- | --- |
| A question about using a Bifröst app | **bc@origo.is** |
| A correction or gap in this documentation | Open an issue in this repository |
| A bug in an app | **bc@origo.is**, with app name, version and environment |
| Commercial and licensing questions | <https://www.origo.is/> |

Issues in this repository are for the documentation site only. Product defects
are tracked internally by Origo.
