The **Bifrost Language Models** page lists all defined AI language models. Each role customizes the AI's behavior by providing skill instructions that are injected into the conversation.

## Fields

| Field | Description |
| --- | --- |
| **Code** | The unique identifier for the language model. |
| **Description** | A short description of what the language model does. |
| **Has Skill** | Indicates whether skill content (instructions) has been defined for this role. |

## Common Tasks

-   **Create a new role:** Click **New** to open a blank Role Card where you can define the code, description, and skill instructions.
-   **Edit a language model:** Select a language model and press Enter or click the row to open the Language Model Card.
-   **Assign to a user:** Open the [Bifrost Chat and User Setup](/help/language-models/bifrost-chat/) and set the Bifrost Language Model Code field.
