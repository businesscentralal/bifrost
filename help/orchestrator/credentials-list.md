**Client Credentials** lists the client credential pairs that Bifrost Orchestrator uses when an
orchestrator entry authenticates against an external service. Open it with **Client Credentials** on
[Bifrost Orchestrator Setup](/help/orchestrator/orchestrator-setup/).

The list is read-only. Choose **New**, or open a line, to work on the
[Client Credentials Card](/help/orchestrator/credentials-card/), where the client ID and client secret
are entered.

## Fields

| Field | Description |
| --- | --- |
| **Code** | The unique code of the credential pair. Orchestrator entries refer to it in **Client Credentials Code**. |
| **Description** | What the credential pair is used for. |
| **Secrets** | **Set** when both the client ID and the client secret have been entered, **Not set** otherwise. Open the card to enter them. |
