**Job Queue Recurring Templates** lists the reusable schedules of the company. A template holds the
weekdays, time window, interval and time zone of a schedule, so many orchestrator entries and
scheduled playbooks can share one schedule and you change it in one place.

Open the list with **Recurring Templates** on
[Bifrost Orchestrator Setup](/help/orchestrator/orchestrator-setup/). Choose **New**, or open a line, to
work on the [Job Queue Recurring Template](/help/orchestrator/recurring-template/) card.

## Fields

| Field | Description |
| --- | --- |
| **Code** | The unique code of the template. |
| **Description** | When the schedule applies. |
| **Time Zone** | The time zone the schedule is read in. |

## Actions

| Action | Description |
| --- | --- |
| **Insert Sample Templates** | Adds a set of common schedules to start from: weekdays every 30 minutes, daily, hourly around the clock, nightly and weekly on Mondays. Templates that already exist with the same code are left as they are. |
