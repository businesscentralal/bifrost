**Job Queue Recurring Templates** lists the reusable schedule patterns available in the company. A template holds the weekdays, time window, interval and time zone for a schedule, so the same pattern can be reused by many orchestrator entries and by scheduled playbooks.

Select a line to open the [Job Queue Recurring Template](/help/nornir/recurring-template/) card.

## Fields

| Field | Description |
| --- | --- |
| **Code** | The unique code of the template. |
| **Description** | The description of the template. |
| **Time Zone** | The time zone the template's schedule is interpreted in. |

## Actions

| Action | Description |
| --- | --- |
| **Insert Sample Templates** | Inserts a set of commonly used schedule templates, so you have something to start from. Existing templates are not overwritten. |
