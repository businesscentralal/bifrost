title: "Select File Account"
---

Use **Select File Account** to choose a file account for a Bifröst storage connection. Open it with **Select File Account** on the [connection card](storage-card), or with the lookup beside **File Account Name**.

## Choose an account

The lookup shows accounts registered for the connector selected on the connection card. Check **Name**, select the account, and confirm your choice. The **Account Id** column is hidden by default and identifies the account.

Cancel to keep the existing selection. If the list is empty, return to [Bifrost Attachments Setup](attachments-setup), register an account through **Storage Setup Wizard**, and check that the selected connector matches that account. After selecting an account, use **Test Connection** on the connection card.
