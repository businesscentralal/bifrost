The **Background Sessions** FactBox appears on the [Bifrost Setup](/help/foundation/bifrost-setup/) page. It lists all active background sessions currently running in the system. Use this panel to monitor and stop individual background sessions when needed.

## Columns

| Column | Description |
| --- | --- |
| **Session ID** | Unique numeric identifier of the background session. |
| **Session Unique ID** | GUID that uniquely identifies this session even when multiple sessions share the same Session ID. |
| **User ID** | The user account running the background session. |

## Actions

| Action | Description |
| --- | --- |
| **Stop Session** | Stops the selected background session. A confirmation is required before the session is terminated. |
| **Refresh** | Reloads the list to show the current state of background sessions. |
