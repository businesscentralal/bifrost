The **Bifrost Note Card** displays the full details of a single notification, including the message body, sender, recipient, and notification type.

## Fields

| Field | Description |
| --- | --- |
| **Subject** | The title or subject line of the notification. |
| **Notification Type** | The category of the notification (e.g., New Record, Approval, Overdue). |
| **Is Read** | Indicates whether the notification has been read. Toggle to update status. |
| **Recipient User ID** | The user this notification was sent to. |
| **Sender User ID** | The user or system that created the notification. |
| **Body** | The full message content of the notification, displayed in a text editor. |

## Actions

| Action | Description |
| --- | --- |
| **Mark as Read** | Sets the notification as read. |
| **Mark as Unread** | Sets the notification back to unread. |
| **Navigate** | Opens the related business record (when a related table is linked). |
