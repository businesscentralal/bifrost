The **Select User or Application** lookup page lists all active Business Central users and registered Entra ID (AAD) applications. It is opened from the [Bifrost Field Accesses](/help/foundation/bifrost-field-accesses/) page when you use the lookup on the **User Name** filter to choose whose restrictions you want to manage.

## Columns

| Column | Description |
| --- | --- |
| **Name** | The display name of the user or Entra ID application. |
| **Source Type** | Indicates whether the entry represents:
-   **User** – a regular Business Central user account.
-   **Application** – an Entra ID (AAD) application using service principal authentication.

 |

## Usage

Select the user or application whose restrictions you want to view or edit, then choose **OK**. The name is written back to the **User Name** filter on the Field Accesses page and the restrictions list is updated to show only that user's entries.
