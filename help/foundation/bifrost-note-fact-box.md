The **Note Thread** FactBox shows all notifications related to the current record as a conversation thread. It displays messages from all users (not filtered to the current user), providing a complete notification history for the record.

## Fields

| Field | Description |
| --- | --- |
| **Subject** | The subject line of each notification in the thread. |
| **Created At** | The timestamp when the notification was created. |

## Actions

| Action | Description |
| --- | --- |
| **View Message** | Opens the full notification message in a read-only modal view. |
