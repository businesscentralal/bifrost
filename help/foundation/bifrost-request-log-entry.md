The **Bifrost Request Log Entry** card shows one outbound request from the [Request Log](/help/foundation/bifrost-request-log/).
The full URL and the request and response bodies are shown only to the user who made the request.

| Group | Contents |
| --- | --- |
| **General** | When the request was sent and by whom. |
| **Request** | The connector, operation, HTTP method, base and full service URL, and the request body. |
| **Result** | The HTTP status, elapsed time, whether it succeeded, the error text and the response body. |

| Action | Description |
| --- | --- |
| **Download Request** | Downloads the request body as a file. |
| **Download Response** | Downloads the response body as a file. |
