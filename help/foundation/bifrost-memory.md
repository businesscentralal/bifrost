The **Bifrost Memory** page manages company-level memory blobs used by Bifrost message types and by Bifrost Bragi (chat). These are persistent knowledge entries that the AI can access across all users in the company, enabling shared context and company-specific information.

## Fields

| Field | Description |
| --- | --- |
| **Id** | A unique identifier (GUID) for the memory entry. |
| **Description** | A short description of what this memory entry contains. |
| **Last Modified** | The date and time the memory was last updated. |
| **Data Size** | The size of the stored data in bytes. |

## Actions

| Action | Description |
| --- | --- |
| **Import** | Imports memory content from an external file. |
| **Export** | Exports the selected memory entry to a file. |
| **Delete** | Deletes the selected memory entry. |
