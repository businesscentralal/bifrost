The **Bifrost Response** FactBox appears on the right side of the [Bifrost Messages](/help/foundation/bifrost-messages/) list. It displays the response data that was generated after the selected bifrost message was processed. The content is read-only.

## Actions

| Action | Description |
| --- | --- |
| **Download File** | Downloads the response data to your computer as a file. The file extension (JSON, XML, or TXT) is determined automatically based on the content type. |

## Notes

-   If the response data is very large (over 30,000 characters), the FactBox shows a message instead of the full content. Use the **Download File** action to retrieve the complete data.
-   The response is only available after the message has been processed (status: _Task completed_).
