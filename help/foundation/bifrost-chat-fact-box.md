The **Chat via Bifrost** fact box lets you chat with Bifröst about the record you are looking at. It
shows a chat when an app that provides one is installed and set up; until then it stays empty. That
app also decides where the answers come from.

| Action | Description |
| --- | --- |
| **Focus** | Opens the chat in a [full-page view](/help/foundation/bifrost-chat/), keeping the conversation and the record context. |
| **User Setup** | Opens your [Bifrost User Setup](/help/foundation/bifrost-user-setup-editor/), where the system prompt for your user is set. |
