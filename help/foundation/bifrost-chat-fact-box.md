The **Chat via Bifrost** fact box lets you chat with Bifröst about the record you are looking at. The
answers come from the language model that is configured for your user; install an application that
provides a language model, such as Bifrost Language Models, to use it.

| Action | Description |
| --- | --- |
| **Focus** | Opens the chat in a [full-page view](/help/foundation/bifrost-chat/), keeping the conversation and the record context. |
| **User Setup** | Opens your [Bifrost User Setup](/help/foundation/bifrost-user-setup-editor/), where the language model and system prompt for your user are set. |
