The **Incoming Document Urls** part on the Incoming Document card lists web addresses linked to the
incoming document, for example the original of a document received through Bifröst. Choose a URL to
open it in the browser.

| Field | Description |
| --- | --- |
| **URL** | A web address associated with the incoming document. |
