The **Bifrost notes** page is your notification inbox. It shows all notification notes addressed to you, sorted newest first. Use it to track approval notifications, system alerts, and messages from other users or integrations.

## Fields

| Field | Description |
| --- | --- |
| **Subject** | The notification title. |
| **Sender User ID** | Who sent the notification. |
| **Notification Type** | The category (e.g., New Record, Approval, Overdue). |
| **Is Read** | Whether you have read this notification. |
| **Created At** | When the notification was created. |

## Actions

| Action | Description |
| --- | --- |
| **Mark as Read** | Marks selected notifications as read. |
| **Mark as Unread** | Marks selected notifications as unread. |
| **Navigate** | Opens the related business record linked to the notification. |
