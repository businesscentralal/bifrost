The **Note Message** page displays a single notification in read-only mode. It is opened from the Note Thread FactBox to allow viewing the full message content without risking accidental modifications.

## Fields

| Field | Description |
| --- | --- |
| **Subject** | The notification subject line. |
| **Sender User ID** | The user or system that sent the notification. |
| **Created At** | The timestamp when the notification was created. |
| **Body** | The full notification message content (read-only). |
