The **Bifrost Applications** list, on the HTTP step of the [Bifrost Setup Wizard](/help/foundation/bifrost-setup-wizard/),
shows every installed Bifröst application and whether it may make outbound HTTP requests.

| Field | Description |
| --- | --- |
| **App Name** | The installed Bifröst application. |
| **HTTP Client Requests** | Whether outbound HTTP is enabled for the application. Most Bifröst applications need it - Bifröst Foundation needs it to reach the licensing service. |

Use **Enable HTTP for all apps** on the wizard step to enable it for every listed application.

## Bifröst App Updates

Every Bifröst user gets a notification on **Bifrost Setup** and their role center while a newer version of an installed Bifröst application is on AppSource, once per session. Earlier notification opt-outs no longer hide available updates. **Show new versions** opens the **Bifröst App Updates** list, for one or several applications.

The list shows each application with an update: the **Installed Version**, the **Latest Version**, the **Released** date, a link to its **Release Notes URL**, and when the information was **Checked At**. Select a line and choose **Release notes** to open the release notes for the selected app, or **Open in AppSource** to open the app's AppSource listing. When the release feed has no AppSource link for the app, **Open in AppSource** searches AppSource by the app name. The list is shown in online environments. It does not install or update anything.
