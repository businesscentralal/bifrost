The **Bifrost Request** FactBox appears on the right side of the [Bifrost Messages](/help/foundation/bifrost-messages/) list. It shows the incoming request payload (data) of the currently selected bifrost message. The content is read-only in this FactBox.

## Actions

| Action | Description |
| --- | --- |
| **Download File** | Downloads the request payload to your computer as a file. The file extension (JSON, XML, or TXT) is determined automatically based on the content type. |
| **Edit** | Opens the [Bifrost Message Editor](/help/foundation/bifrost-message-editor/) page where you can modify the request data. This action is only enabled if you have write permission on the Bifrost Messages table. |
