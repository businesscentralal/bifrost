---

Use **National Registry Entries** to review national registry information retrieved through Umsjá.
Open it with **National Registry Entries** on **Bifrost Iceland Setup**.

## Information on the page

The list shows the registration number, name and address of each entry, along with the registry
attributes available for it, such as record type, family information and registration status.
Filter the list to the information needed for your task.

The **Umsja Fade Reasons** list shows the code and description used to explain a record's fade status.
It is a reference list, not a form for changing national registry information.

## Refreshing the copy

Registry lookups and synchronization retrieve information through the configured Umsjá service.
An administrator configures the service on **Bifrost Iceland Setup**. Use an assistant's live
operation description when requesting a lookup or synchronization.

## Delete All

**Delete All** asks for confirmation and clears the stored registry copy. The registry copy is shared
across companies in the same Business Central environment: this action affects all of them. Coordinate
with their administrators before confirming. It does not change the national registry at Umsjá.

To get information again after clearing the copy, run the appropriate authorized registry retrieval.

## Access and personal data

Registry information can contain personal data. Restrict access and retain it only for the company's
legitimate work. Follow [data access](/documentation/end-customers/data-access/) and
[permission guidance](/documentation/end-customers/permissions/) when arranging access.
