# Leiðbeiningar

Uppsetning Bifröst er í [Settu það upp](/setup/). Þessi hluti er fyrir það sem kemur á eftir: notkun, rekstur og
tengingu við það. Byrjaðu á síðunni fyrir þitt hlutverk.

## Ef Business Central er þitt {#if-business-central-is-yours}

| Þú ert … | Lestu | Um |
|---|---|---|
| **Notandi** | [Notendur](/documentation/end-customers/users/) | Hvað þú getur spurt um, hvað það gerir ekki, og hvað á að gera þegar það segir nei |
| **Kerfisstjóri** | [Kerfisstjórar](/documentation/end-customers/administrators/) | Notendur, annálar, leyndarmál, stillingarnar, notkun, og það sem þú berð ábyrgð á |
| | [Hvað fulltrúar lesa og breyta](/documentation/end-customers/data-access/) | Breytingaskrárverndin, reitaaðgangur, viðkvæmir reitir, og gögnin sem Bifröst ver alltaf |
| | [Heimildasamstæður og hlið](/documentation/end-customers/permissions/) | Hvaða heimildasamstæður á að gefa hverjum, og hvernig hliðin virka ofan á eigin heimildir notanda |
| **Forritari** | [Forritarar](/documentation/end-customers/developers/) | Tenging annars kerfis, stýring frá fulltrúa, og tilvísunin |

## Fyrir alla {#for-everyone}

[Hvernig Bifröst virkar](/documentation/how-it-works/) útskýrir hugmyndirnar einu sinni: skilaboðategundir, hliðið eina
sem hvert kall fer í gegnum, og hvernig fulltrúi finnur og kallar á rétta aðgerð.
