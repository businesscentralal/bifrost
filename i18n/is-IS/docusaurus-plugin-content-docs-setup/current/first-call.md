# Skref 5: Gerðu fyrsta kallið

**Hvern þarf:** Kerfisstjórann, síðan hvern notanda.

1. **Athugaðu uppsetninguna.** Uppsetning Bifröst opnast án uppsetningartilkynningar efst, og hver kallandi hefur
   heimildirnar úr [skrefi 2](/setup/business-central/#give-people-and-apps-permission), með aðeins þau bókunarhlið
   sem hann þarf.
2. **Spurðu einnar spurningar.** Í tengdum aðstoðarmanni spyrðu *„Hver er ég í Business Central?"*. Kallið birtist á
   **Bifröst skilaboðum**, með notandann sem þú bjóst við sem kallanda.
3. **Prófaðu eitthvað raunverulegt.** [Prófaðu](/try-it-out/) hefur spurningar til að byrja á, frá einfaldri spurningu
   að breytingu sem þú forskoðar fyrst.
4. **Leyfðu notendunum að tengjast.** Hver notandi bætir Bifröst við aðstoðarmanninn sinn eins og í
   [skrefi 3](/setup/connect-your-ai/#add-bifröst-to-the-assistant), og skráir sig inn sem hann sjálfur. Sendu þeim
   [Notkun Bifröst](/documentation/end-customers/users/): hvað þeir geta spurt um, hvað það gerir ekki, og hvað á að gera
   þegar það segir nei.

Þar með er uppsetningunni lokið. Héðan í frá, sjá
[Leiðbeiningar fyrir kerfisstjóra](/documentation/end-customers/administrators/).
