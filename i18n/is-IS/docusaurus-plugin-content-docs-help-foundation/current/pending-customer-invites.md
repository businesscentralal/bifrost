**Óafgreidd boð viðskiptavinar** opnast þegar þú velur **Skrá sem viðskiptavinur** og fleiri en einn
samstarfsaðili hefur boðið leigjandanum þínum. Veldu samstarfsaðilann sem þú vilt starfa með.

| Reitur | Lýsing |
| --- | --- |
| **Gælunafn samstarfsaðila** | Heitið sem samstarfsaðilinn gaf leigjandanum þínum. |
| **Tætigildi leigjanda samstarfsaðila** | Samstarfsaðilinn sem sendi boðið. |
| **Boðið (UTC)** | Hvenær boðið var sent (UTC). |

Veldu línu og síðan **Samþykkja**. Leigjandinn þinn fer þá á **áskriftarleyfi** og samstarfsaðilinn
rukkar fyrir notkun þína. Aðeins leyfisstjóri getur samþykkt boð.
