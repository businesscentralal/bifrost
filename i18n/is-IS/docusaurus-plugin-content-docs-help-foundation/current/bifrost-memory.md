Síðan **Bifröst minni** sýnir allt fyrirtækjaminni (company memory) sem er vistað í Bifröst kerfinu. Þetta minni er samnýtt af öllum notendum í fyrirtækinu og inniheldur sameiginlegar upplýsingar og stillingar.

## Reitir

| Reitur | Lýsing |
| --- | --- |
| **Lykill** | Auðkenni minnisskrárinnar. |
| **Gildi** | Innihald minnisskrárinnar. |
| **Síðast breytt** | Dagsetning síðustu breytingar. |
| **Breytt af** | Notandinn sem gerði síðustu breytingu. |

## Aðgerðir

| Aðgerð | Lýsing |
| --- | --- |
| **Nýtt** | Býr til nýja minnisskrá. |
| **Breyta** | Breytir innihaldi valinnar skráar. |
| **Eyða** | Eyðir valinni minnisskrá. |
