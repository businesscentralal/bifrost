**Skilaboðaþráðurinn** er upplýsingareitur sem sýnir öll skilaboð sem tengjast ákveðinni færslu. Hann birtist á hliðarsvæði síðunnar og sýnir samtalsögu í tímaröð.

## Reitir

| Reitur | Lýsing |
| --- | --- |
| **Sendandi** | Hver sendi skilaboðin. |
| **Dagsetning** | Hvenær skilaboðin voru send. |
| **Efni** | Stutt yfirlit yfir innihald skilaboðanna. |

## Aðgerðir

| Aðgerð | Lýsing |
| --- | --- |
| **Opna skilaboð** | Opnar skilaboðin í [lesglugga](/help/foundation/bifrost-note-message/). |
| **Nýtt skilaboð** | Býr til nýtt skilaboð í þessum þræði. |
