Upplýsingareiturinn **Spjalla með Bifröst** gerir þér kleift að spjalla við Bifröst um færsluna sem
þú ert að skoða. Svörin koma frá mállíkaninu sem er stillt fyrir notandann þinn; settu upp forrit sem
býður upp á mállíkan, til dæmis Bifrost Language Models, til að nota hann.

| Aðgerð | Lýsing |
| --- | --- |
| **Fókus** | Opnar spjallið á [heilli síðu](/help/foundation/bifrost-chat/) og heldur samtalinu og samhengi færslunnar. |
| **Notandauppsetning** | Opnar [notandauppsetningu Bifröst](/help/foundation/bifrost-user-setup-editor/) fyrir notandann þinn, þar sem mállíkan og kerfisfyrirmæli eru stillt. |
