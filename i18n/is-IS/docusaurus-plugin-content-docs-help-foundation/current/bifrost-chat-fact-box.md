title: "Spjalla með Bifröst"
---

Upplýsingareiturinn **Spjalla með Bifröst** gerir þér kleift að spjalla við Bifröst um færsluna sem
þú ert að skoða. Þar birtist spjall þegar forrit sem býður upp á spjall hefur verið sett upp og
stillt; fram að því er reiturinn tómur. Það forrit ræður líka hvaðan svörin koma.

| Aðgerð | Lýsing |
| --- | --- |
| **Fókus** | Opnar spjallið á [heilli síðu](/help/foundation/bifrost-chat/) og heldur samtalinu og samhengi færslunnar. |
| **Notandauppsetning** | Opnar [notandauppsetningu Bifröst](/help/foundation/bifrost-user-setup-editor/) fyrir notandann þinn, þar sem kerfisleiðbeiningar notandans eru stilltar. |
