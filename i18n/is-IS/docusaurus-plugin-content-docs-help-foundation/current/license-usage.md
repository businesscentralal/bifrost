Síðan **Notkunarfærslur Bifröst** sýnir notkunina sem tilkynnt hefur verið til leyfisþjónustunnar: eina
færslu fyrir hvert fyrirtæki, dag og pott. Opnaðu hana með **Leyfisnotkun** á síðunni [Uppsetning Bifröst](/help/foundation/bifrost-setup/)
fyrir eigin leigjanda, eða með **Skoða notkun** á [Umsjón viðskiptavina](/help/foundation/customer-management/)
eða [Umsjón samstarfsaðila](/help/foundation/partner-management/) fyrir viðskiptavin eða samstarfsaðila.
Síðan krefst leyfisstjórnunarheimildar.

## Síur

| Reitur | Lýsing |
| --- | --- |
| **Fyrirtækjasía** | Sýnir aðeins eitt fyrirtæki. Sláðu inn heiti eða notaðu uppflettinguna ([Fyrirtæki](/help/foundation/company-name-lookup/)). Hafðu reitinn auðan til að sjá öll fyrirtæki í núverandi yfirliti. |
| **Sía leyfistegundar** | **Notandi** eða **Forritsskráning**; hafðu reitinn auðan til að sjá báða pottana. |
| **Upphafsdagsetning** / **Lokadagsetning** | Takmarka færslurnar við tiltekið dagsetningabil. |
| **Færslur á síðu** | Hve margar færslur eru sóttar í einu (25 til 1.000). |
| **Síða** | Bilið sem er sýnt og heildarfjöldi færslna sem passa við síurnar. |

## Dálkar

| Reitur | Lýsing |
| --- | --- |
| **Heiti fyrirtækis** | Fyrirtækið sem notkunin tilheyrir. |
| **Dagsetning** | Dagurinn sem skilaboðin voru unnin. |
| **Tegund leyfis** | Potturinn sem var gjaldfærður. |
| **Magn** | Fjöldi gjaldskyldra skilaboða. |
| **Skráð þann** | Hvenær færslan var tilkynnt til leyfisþjónustunnar. |

## Aðgerðir

| Aðgerð | Lýsing |
| --- | --- |
| **Uppfæra** | Sækir fyrstu síðuna aftur með núverandi síum. |
| **Fyrri** / **Næsta** | Flettir á milli síðna. |

Notkun er tilkynnt einu sinni á dag; veldu **Samstilla** á Uppsetning Bifröst til að tilkynna skilaboð
dagsins strax. Sjá [Notkun og reikningagerð](/foundation/licensing/usage-and-billing/).
