Upplýsingareiturinn **Bifröst beiðni** birtist hægra megin á [Bifröst skilaboð](/help/foundation/bifrost-messages/) listanum. Hann sýnir komandi beiðnigögn (gagnafarm) valins Bifröst skilaboðs. Innihaldið er skrifvarið í þessum upplýsingareit.

## Aðgerðir

| Aðgerð | Lýsing |
| --- | --- |
| **Sækja skrá** | Sækir gagnafarm beiðninnar á tölvuna þína sem skrá. Skráarendingin (JSON, XML eða TXT) er ákvörðuð sjálfkrafa eftir efnistegund. |
| **Breyta** | Opnar [Ritil Bifröst skilaboða](/help/foundation/bifrost-message-editor/) þar sem þú getur breytt beiðnigögnunum. Þessi aðgerð er aðeins virk ef þú hefur skrifheimild á töflu Bifröst skilaboða. |
