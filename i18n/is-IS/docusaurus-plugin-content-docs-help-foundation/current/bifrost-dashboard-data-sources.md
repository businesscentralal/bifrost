**Gagnagjafar mælaborðs** sýnir hvaðan tölur [mælaborðs](/help/foundation/bifrost-dashboards/) koma. Hver lína er einn gagnagjafi sem er lesinn þegar mælaborðið uppfærist. Síðan er skrifvarin. Gagnagjafar eru skrifaðir ásamt mælaborðinu og fjarlægðir þegar mælaborðið er fjarlægt.

Opnaðu síðuna með **Gagnagjafar** á lista mælaborða eða í skoðara mælaborðs. Hún sýnir þá aðeins gagnagjafa þess mælaborðs.

## Reitir {#fields}

| Reitur | Lýsing |
| --- | --- |
| **Kóði mælaborðs** | Mælaborðið sem þessi gagnagjafi fyllir. |
| **Raðnúmer** | Staða gagnagjafans meðal gagnagjafa mælaborðsins. |
| **Lykill gagnagjafa** | Lykillinn sem mælaborðið finnur gögn þessa gagnagjafa undir. |
| **Skilaboðagerð** | Lestraraðgerðin sem uppfærslan kallar á til að sækja gögnin. |
| **Athugasemd** | Athugasemd um þennan gagnagjafa. |
| **Hámarksfjöldi síðna** | Hámarksfjöldi síðna sem uppfærslan les af svari í síðum. |
| **Síðustærð** | Hversu margar línur uppfærslan les á hverri síðu. |
| **Beiðni** | Beiðnin sem uppfærslan sendir þeirri aðgerð. |

## Aðgerðir {#actions}

Síðan hefur engar eigin aðgerðir. Notaðu bakkhnappinn til að fara aftur í mælaborðið.

## Algeng verkefni {#common-tasks}

- **Finna hvað fæðir myndrit:** berðu gögn myndritsins saman við **Lykill gagnagjafa** og lestu **Beiðni**.
- **Skilja hæga uppfærslu:** berðu saman **Hámarksfjöldi síðna** og **Síðustærð**. Saman takmarka þau hve margar línur uppfærsla les úr gagnagjafa.
