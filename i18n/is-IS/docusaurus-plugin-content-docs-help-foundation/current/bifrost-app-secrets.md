**Leyndarmál forrita Bifröst** telur upp leyndarmálin - lykilorð, lykla og tóka - sem uppsett
Bifröst-forrit þurfa, og hvort gildi hafi verið vistað. Gildið sjálft er aldrei sýnt. Opnaðu síðuna
úr **Leyndarmál** á síðunni [Uppsetning Bifröst](/help/foundation/bifrost-setup/) til að sjá öll
forrit, eða af uppsetningarsíðu forrits til að sjá aðeins það forrit.

| Reitur | Lýsing |
| --- | --- |
| **Heiti forrits** | Forritið sem þarf leyndarmálið. |
| **Kóði leyndarmáls** | Kóðinn sem forritið notar fyrir leyndarmálið. |
| **Lýsing** | Til hvers forritið notar leyndarmálið. |
| **Umfang** | **Fyrirtæki** - eitt gildi fyrir allt fyrirtækið; **Fyrirtæki og notandi** - hver notandi skráir sitt eigið. |
| **Gildi skráð** | Hvort gildi hefur verið vistað. |
| **Skráð þann** / **Nafn skrásetjara** | Hvenær og af hverjum gildið var síðast skráð. |

| Aðgerð | Lýsing |
| --- | --- |
| **Skrá...** | Skráðu gildið í glugganum [Skrá leyndarmál](/help/foundation/set-secret-dialog/). |
| **Hreinsa** | Fjarlægir vistaða gildið en heldur leyndarmálinu skráðu, svo að forritið sýnir það áfram sem vantandi. |

Gildi leyndarmála eru geymd í varinni geymslu, sér fyrir hvert fyrirtæki; þau eru aldrei afrituð á
milli fyrirtækja. Skilaboðategund sem þarf leyndarmál sem vantar er óvirk þar til gildið hefur verið
skráð.
