**Tilkynningaspjaldið** sýnir nákvæmar upplýsingar um eina tilkynningu. Hér getur þú lesið allt innihald skilaboðanna, séð tengda færslu og svarað skilaboðum.

## Reitir

| Reitur | Lýsing |
| --- | --- |
| **Efni** | Efnislína tilkynningarinnar. |
| **Sendandi** | Nafn þess sem sendi tilkynninguna. |
| **Dagsetning** | Dagur og tími sem tilkynningin var send. |
| **Lesið** | Hvort tilkynningin hefur verið lesin. |
| **Tengd tafla** | Tegund færslu sem tilkynningin tengist. |
| **Tengd færsla** | Auðkenni færslunnar sem tilkynningin tengist. |

## Aðgerðir

| Aðgerð | Lýsing |
| --- | --- |
| **Svara** | Opnar glugga til að svara tilkynningunni. |
| **Merkja sem lesna** | Merkir tilkynninguna sem lesna. |
| **Opna tengda færslu** | Opnar færsluna sem tilkynningin tengist. |
