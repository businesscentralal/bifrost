Í glugganum **Skrá leyndarmál** skráir þú gildi leyndarmáls fyrir Bifröst-forrit. Hann opnast úr
[Leyndarmál forrita Bifröst](/help/foundation/bifrost-app-secrets/), úr
[auðkennaskrefi](/help/foundation/wizard-credentials/) leiðsagnarinnar eða af uppsetningarsíðu forrits.

| Reitur | Lýsing |
| --- | --- |
| **Leyndarmál** / **Lýsing** | Leyndarmálið sem þú ert að skrá og til hvers það er notað. |
| **Gildi** | Gildi leyndarmálsins. Það er hulið á meðan þú slærð það inn. |
| **Staðfesta gildi** | Birtist fyrir lykilorð: sláðu gildið inn aftur; bæði verða að vera eins. |
| **Gildi (Base64)** | Birtist fyrir löng gildi, til dæmis Base64-kóðað skilríki. |

Veldu **Í lagi** til að vista gildið. Það fer í varða geymslu og er aldrei sýnt aftur, aldrei skrifað
í töflu og aldrei sent með fjarmælingum.
