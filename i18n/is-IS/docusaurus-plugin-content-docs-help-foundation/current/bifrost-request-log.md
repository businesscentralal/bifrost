**Annáll beiðna Bifröst** telur upp þær HTTP-beiðnir út á við sem Bifröst-forrit sendu fyrir þína
hönd, nýjustu fyrst. Hver notandi sér aðeins eigin færslur. Opnaðu hann úr **Annáll beiðna** á
síðunni [Uppsetning Bifröst](/help/foundation/bifrost-setup/).

| Reitur | Lýsing |
| --- | --- |
| **Færslunúmer** | Númer færslunnar. |
| **Tímastimpill** | Hvenær beiðnin var send. |
| **Heiti þjónustu** / **Tegund** | Þjónustan og tengillinn sem sendi beiðnina. |
| **Aðgerð** | Aðgerðin sem var framkvæmd. |
| **HTTP aðferð** / **Grunnslóð þjónustu** | Aðferð og hýsill beiðninnar. |
| **HTTP staða** / **Tókst** | Stöðukóðinn sem var skilað og hvort beiðninni lauk án villu. |
| **Tími** | Hve langan tíma beiðnin tók. |
| **Notandi** | Notandinn sem sendi beiðnina. |

| Aðgerð | Lýsing |
| --- | --- |
| **Eyða færslum eldri en 7 daga** | Fjarlægir færslurnar þínar sem eru eldri en sjö daga. |
| **Eyða öllum færslum** | Fjarlægir allar færslurnar þínar. |

Opnaðu færslu til að sjá [nánari upplýsingar](/help/foundation/bifrost-request-log-entry/). Meginmál
beiðna og svara er vistað með viðkvæm gildi hulin; á meðan **Villuleitarstilling beiðna** er virk í
Uppsetning Bifröst er það vistað í heild - slökktu aftur á henni þegar villuleit er lokið.
