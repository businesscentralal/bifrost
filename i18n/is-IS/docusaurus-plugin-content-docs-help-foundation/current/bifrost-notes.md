Síðan **Bifröst tilkynningar** er innhólf notandans fyrir öll skilaboð og tilkynningar sem berast í gegnum Bifröst kerfið. Hér sérðu ný og ólesin skilaboð, getur opnað þau, og svarað.

## Reitir

| Reitur | Lýsing |
| --- | --- |
| **Efni** | Efnislína tilkynningarinnar. |
| **Sendandi** | Nafn sendanda. |
| **Dagsetning** | Hvenær tilkynningin barst. |
| **Lesið** | Hvort tilkynningin hefur verið opnuð. |
| **Tegund** | Tegund tilkynningar (skilaboð, kerfisvilla, viðvörun, o.s.frv.). |

## Aðgerðir

| Aðgerð | Lýsing |
| --- | --- |
| **Opna** | Opnar valda tilkynningu á [tilkynningaspjaldi](/help/foundation/bifrost-note-card/). |
| **Merkja sem lesnar** | Merkir allar valdar tilkynningar sem lesnar. |
| **Eyða** | Eyðir völdum tilkynningum. |
