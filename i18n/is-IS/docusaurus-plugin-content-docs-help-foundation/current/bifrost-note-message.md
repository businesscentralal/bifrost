**Skilaboð** síðan er skrifvarinn gluggi sem sýnir allt innihald eins skilaboðs. Hann opnast þegar þú smellir á skilaboð í þræði eða tilkynningalista.

## Reitir

| Reitur | Lýsing |
| --- | --- |
| **Efni** | Efnislína skilaboðanna. |
| **Sendandi** | Nafn sendanda. |
| **Dagsetning** | Dagsetning og tími skilaboðanna. |
| **Meginmál** | Allt innihald skilaboðanna. |
