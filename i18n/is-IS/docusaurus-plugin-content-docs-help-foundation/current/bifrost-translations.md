Síðan **Bifröst þýðingar** gerir stjórnendum kleift að viðhalda þýðingarfærslum. Ytri kerfi geta notað þessar færslur til að sækja þýddan texta fyrir tiltekinn skilaboðauppruna, tungumál og enskan upprunatexta.

## Dálkar

| Dálkur | Lýsing |
| --- | --- |
| **Uppruni** | Skilaboðauppruninn sem þessi þýðingarfærsla tilheyrir (t.d. skilaboðagerð, eining eða auðkenni ytra kerfis). |
| **Windows tungumálaauðkenni** | Tölulegt Windows tungumálaauðkenni markmálsins (t.d. 1033 fyrir ensku, 1039 fyrir íslensku). |
| **Heiti tungumáls** | Birtingarheiti markmálsins (flett upp sjálfkrafa úr Windows tungumálaauðkenninu). |
| **Upprunatexti** | Upprunalegi enski textinn sem þarf að þýða. |
| **Marktexti** | Þýddur texti á markmálinu. |

## Hvernig á að nota

1.  Bættu við nýrri línu fyrir hverja þýðingu sem þú þarft.
2.  Sláðu inn **Uppruna** til að flokka þýðinguna (venjulega skilaboðagerð eða heiti einingar).
3.  Stilltu **Windows tungumálaauðkenni** fyrir markmálið.
4.  Sláðu inn upprunalega textann í **Upprunatexta** og þýðinguna í **Marktexta**.

## Ábendingar

-   Þýðingar eru notaðar á keyrslutíma af vinnslu Bifröst skilaboða þegar tungumálaháð svör eru skilað til ytri kerfa.
-   Þú getur búið til margar þýðingar fyrir sama upprunatexta á mismunandi tungumálum.
-   Hægt er að nálgast þessa síðu beint úr [Bifröst uppsetningu](/help/foundation/bifrost-setup/) með _Bifröst þýðingar_ aðgerðinni.
