Listinn **Auðkenni**, í valfrjálsu auðkennaskrefi [Uppsetningarleiðsagnar Bifröst](/help/foundation/bifrost-setup-wizard/),
sýnir þau auðkenni sem uppsett Bifröst-forrit þurfa, svo að þú getir skráð þau sem enn vantar.
Gildin sjálf eru aldrei sýnd.

| Reitur | Lýsing |
| --- | --- |
| **Forrit** | Forritið sem þarf auðkennið. |
| **Lýsing** | Til hvers forritið notar það. |
| **Umfang** | Hvort gildið er sameiginlegt öllu fyrirtækinu eða hver notandi skráir sitt eigið. |
| **Gildi skráð** | Hvort gildi hefur verið vistað. |

| Aðgerð | Lýsing |
| --- | --- |
| **Skrá gildi...** | Skráðu gildið í glugganum [Skrá leyndarmál](/help/foundation/set-secret-dialog/). |
| **Hreinsa** | Fjarlægir vistaða gildið; forritið sýnir auðkennið áfram sem vantandi. |

Þú getur sleppt þessu skrefi og skráð gildin síðar úr **Leyndarmál** í Uppsetning Bifröst - sjá
[Leyndarmál forrita Bifröst](/help/foundation/bifrost-app-secrets/).
