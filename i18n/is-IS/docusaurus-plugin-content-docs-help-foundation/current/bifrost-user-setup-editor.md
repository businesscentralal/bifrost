**Ritill notandauppsetningar** gerir þér kleift að breyta JSON-uppsetningunni fyrir hvern notanda Bifröst kerfisins. Þetta er ítarlegt ritilsviðmót sem sýnir og leyfir breytingar á öllum stillingum notandans.

## Reitir

| Reitur | Lýsing |
| --- | --- |
| **Notandanafn** | Auðkenni notandans sem stillingarnar eiga við. |
| **Uppsetning (JSON)** | JSON-innihald notandauppsetningarinnar. Hægt er að breyta beint. |

## Aðgerðir

| Aðgerð | Lýsing |
| --- | --- |
| **Vista** | Vistar breytingarnar. |
| **Endurstilla** | Endurstillir uppsetninguna á sjálfgefið gildi. |
