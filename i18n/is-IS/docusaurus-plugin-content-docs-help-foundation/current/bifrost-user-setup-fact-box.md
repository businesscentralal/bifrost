**Forskoðun notandauppsetningar** er upplýsingareitur sem birtist á hliðarsvæði síðna og sýnir fljótlegt yfirlit yfir stillingar núverandi notanda í Bifröst kerfinu.

## Reitir

| Reitur | Lýsing |
| --- | --- |
| **Notandanafn** | Nafn notandans. |
| **Stilling** | Samantekt á uppsetningargildum notandans. |

## Aðgerðir

| Aðgerð | Lýsing |
| --- | --- |
| **Breyta** | Opnar [ritil notandauppsetningar](/help/foundation/bifrost-user-setup-editor/) til að gera breytingar. |
