title: "Forskoðun notandauppsetningar"
---

Upplýsingareiturinn **Forskoðun notandauppsetningar** sýnir yfirlit yfir uppsetningu Bifröst fyrir valinn
notanda. Hann birtist á [Bifröst notandauppsetning](/help/foundation/bifrost-user-setup-list/) og í
[Ritli notandauppsetningar](/help/foundation/bifrost-user-setup-editor/). Hann sýnir heiti tengdra færslna, ekki
aðeins kóða, svo þú getir yfirfarið uppsetninguna í fljótu bragði.

## Upplýsingar sem birtast {#displayed-information}

| Reitur | Lýsing |
| --- | --- |
| **Kerfisleiðbeiningar** | Forskoðun á kerfisleiðbeiningum notandans. |
| **Gjaldskyld skilaboð í þessum mánuði** | Gjaldskyld skilaboð notandans í núverandi fyrirtæki frá fyrsta degi mánaðarins til dagsins í dag. Veldu fjöldann til að sjá skilaboðin. |
| **Gjaldskyld skilaboð í síðasta mánuði** | Gjaldskyld skilaboð notandans í núverandi fyrirtæki í öllum síðasta almanaksmánuði. Veldu fjöldann til að sjá skilaboðin. |
| **Fjárhagsreikningur**, **Starfsmaður**, **Viðskiptamaður**, **Lánardrottinn**, **Forði**, **Sölumaður**, **Tengiliður**, **Birgðageymsla** | Heiti tengdu færslnanna. |

## Aðgerðir {#actions}

| Aðgerð | Lýsing |
| --- | --- |
| **Breyta uppsetningu** | Opnar [Ritil notandauppsetningar](/help/foundation/bifrost-user-setup-editor/) til að breyta uppsetningu þessa notanda. |
