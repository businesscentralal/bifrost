Síðan **Auðkenni kallara** sýnir lista yfir skráða ytri kallara sem hafa aðgang að Bifröst API. Hvert auðkenni er tengt nafni, leyfi og skilgreiningum sem stýra því hvaða skilaboðagerðir kallarinn má nota.

## Reitir

| Reitur | Lýsing |
| --- | --- |
| **Kóði** | Einkvæmt auðkenni kallarans. |
| **Nafn** | Lýsandi nafn á kallaranum. |
| **Virkt** | Hvort kallarinn er virkur og getur sent beiðnir. |
| **Takmarkað við skilaboðagerð** | Ef valið, getur kallarinn aðeins notað tiltekna skilaboðagerð. |

## Aðgerðir

| Aðgerð | Lýsing |
| --- | --- |
| **Nýtt** | Býr til nýtt auðkenni. |
| **Eyða** | Eyðir völdu auðkenni. |
