Spjaldið **Færsla úr annál beiðna Bifröst** sýnir eina beiðni út á við úr [annál beiðna](/help/foundation/bifrost-request-log/).
Full vefslóð og meginmál beiðni og svars eru aðeins sýnd notandanum sem sendi beiðnina.

| Flokkur | Innihald |
| --- | --- |
| **Almennt** | Hvenær beiðnin var send og af hverjum. |
| **Beiðni** | Tengillinn, aðgerðin, HTTP-aðferðin, grunnslóð og full slóð þjónustunnar og meginmál beiðninnar. |
| **Niðurstaða** | HTTP-staðan, tíminn sem beiðnin tók, hvort hún tókst, villutextinn og meginmál svarsins. |

| Aðgerð | Lýsing |
| --- | --- |
| **Hlaða niður beiðni** | Hleður niður meginmáli beiðninnar sem skrá. |
| **Hlaða niður svari** | Hleður niður meginmáli svarsins sem skrá. |
