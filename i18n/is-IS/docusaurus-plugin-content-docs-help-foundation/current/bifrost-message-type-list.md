Undirsiðan **Tiltækar skilaboðategundir** birtist á síðunni [Bifröst uppsetning](/help/foundation/bifrost-setup/). Hún sýnir allar skilaboðategundir sem eru skráðar í kerfinu — bæði innbyggðar tegundir og tegundir sem bætt hefur verið við með viðbótarforritum. Nota má þennan glugga til að yfirfara tiltækar skilaboðategundir og hlaða niður hjálparskjölun þeirra.

## Dálkar

| Dálkur | Lýsing |
| --- | --- |
| **Heiti** | Innra heiti skilaboðategundarinnar (t.d. `Customer.CreditLimit.Get`). Þetta er gildið sem notað er í `type` reitnum í Bifröst skilaboðum. |
| **Lýsing** | Stutt lýsing á því hvað skilaboðategundin gerir. |
| **Afmarkanir töflunúmer** | BC töflunúmerið sem þessi skilaboðategund afmarkar, eða `0` ef hún á við allar töflur. |
| **Stefna** | Hvort skilaboðategundin sé _inn_ (gögn skrifuð í BC) eða _út_ (gögn lesin úr BC). |

## Aðgerðir

| Aðgerð | Lýsing |
| --- | --- |
| **Hlaða niður hjálp** | Hleður niður hjálparskjölun fyrir valda skilaboðategund sem Markdown-skrá. Innihaldið er búið til af útfærslu skilaboðategundarinnar sjálfrar. |
