Lists unfulfilled prerequisites that prevent a claimant frá creating claim templates.

## Beiðni
```json
{ "claimantNationalId": "6306251060", "skip": 0, "take": 50 }
```
`claimantNationalId` er nauðsynlegt. `skip`/`take` eru valfrjálst, mapped til `page`/`perPage`.
