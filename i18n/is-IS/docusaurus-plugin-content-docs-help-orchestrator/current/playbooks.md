**Keðja** er leiðbeinandi runa af Bifröst skilaboðategundum. Hvert skref kallar eina skilaboðagerð og svar skrefs getur stýrt beiðni næsta skrefs, verið ítrað sem fylki eða ráðið hvaða leið keyrslan fer.

Þessi listi sýnir allar keðjur í fyrirtækinu ásamt niðurstöðu síðustu keyrslu. Veldu línu til að opna spjaldið [Bifröst keðja](/help/orchestrator/playbook-card/).

## Reitir

| Reitur | Lýsing |
| --- | --- |
| **Kóði** | Einstæður kóði keðjunnar. |
| **Lýsing** | Lýsing keðjunnar. |
| **Staða síðustu keyrslu** | Staða síðustu keyrslu. |
| **Síðasta keyrsla** | Hvenær keðjan var síðast keyrð. |
