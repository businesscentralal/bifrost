Spjaldið **Upplýsingar um keðjukeyrslu** sýnir eina keyrslu í heild: tímasetningar, teljara, villur og skrá yfir hvert skref sem keyrt var. Spjaldið er óbreytanlegt.

## Almennt

| Reitur | Lýsing |
| --- | --- |
| **Kóði keðju** | Keðjan sem var keyrð. |
| **Staða** | Staða keyrslunnar. |
| **Hafið** | Hvenær keyrslan hófst. |
| **Lokið** | Hvenær keyrslunni lauk. |
| **Heildartími** | Heildartími keyrslunnar. |

## Teljarar

| Reitur | Lýsing |
| --- | --- |
| **Skref keyrð** | Fjöldi skrefa sem voru keyrð. |
| **Skref mistókust** | Fjöldi skrefa sem mistókust. |
| **Hlutir unnir** | Heildarfjöldi hluta sem unnir voru í öllum ítrunum. |

## Villa

Hlutinn **Villa** birtist aðeins þegar keyrslan skilaði villu. Hann inniheldur villuboðin sem stoppuðu keyrsluna.

## Atburðaskrá skrefa

Hlutinn **Atburðaskrá skrefa** sýnir hverja skrefkeyrslu í keyrslunni, þar á meðal eina línu á hverja ítrun þegar skref ítrar yfir fylki. Veldu línu til að sjá beiðni, svar og tímasetningu í upplýsingareitnum **Valið skref**.
