Upplýsingareiturinn **Síðasta keyrsla** á spjaldinu [Bifröst keðja](/help/orchestrator/playbook-card/) tekur saman síðustu keyrslu keðjunnar svo þú sjáir í fljótu bragði hvort hún tókst. Hann er auður þar til keðjan hefur keyrt. Upplýsingareiturinn er óbreytanlegur.

## Reitir {#fields}

| Reitur | Lýsing |
| --- | --- |
| **Staða** | Hvernig keyrslan endaði, til dæmis _Lokið_ eða _Mistókst_. Veldu gildið til að opna keyrsluna í [Upplýsingum um keðjukeyrslu](/help/orchestrator/playbook-instance-card/). |
| **Byrjaði** | Hvenær keyrslan hófst. |
| **Heildartími** | Hversu lengi keyrslan stóð. |
| **Skref keyrð** | Fjöldi skrefa sem keyrðu. |
| **Skref mistókst** | Fjöldi skrefa sem mistókust. Veldu gildið til að opna keyrsluna og sjá hver þau voru. |
| **Hlutir unnir** | Fjöldi hluta sem unnir voru í öllum ítrunum. |
| **Villuboð** | Villan sem stöðvaði keyrsluna. Aðeins sýnt þegar villa varð. |

Fyrir eldri keyrslur skaltu velja **Keyrsluskrá** á spjaldinu til að opna [keyrsluskrá keðju](/help/orchestrator/playbook-instances/).
