**Keyrsluskrá keðju** sýnir keyrslur keðja, flokkaðar eftir keðju með nýjustu keyrsluna efst. Byrjaðu
hér þegar þú þarft að vita hvort keðja keyrði eða hvers vegna hún mistókst. Listanum er ekki hægt að
breyta. Opnaðu línu til að sjá keyrsluna skref fyrir skref á
[Upplýsingar um keðjukeyrslu](/help/orchestrator/playbook-instance-card/).

Opnaðu skrána með **Keyrsluskrá keðju** á
[Uppsetning Bifröst stjórnanda](/help/orchestrator/orchestrator-setup/), eða með **Keyrsluskrá** á keðju,
sem síar hana á þá keðju.

Dálkurinn **Staða** er litaður: keyrslur sem lauk eru grænar, keyrslur sem mistókust rauðar og keyrslur
í gangi gular.

## Reitir {#fields}

| Reitur | Lýsing |
| --- | --- |
| **Kóði keðju** | Keðjan sem keyrði. |
| **Staða** | Staða keyrslunnar. |
| **Byrjaði** | Hvenær keyrslan hófst. |
| **Lauk** | Hvenær keyrslunni lauk. |
| **Heildartími** | Hve langan tíma keyrslan tók. |
| **Skref keyrð** | Fjöldi skrefa sem keyrðu. |
| **Skref mistókst** | Fjöldi skrefa sem mistókust. |
| **Hlutir unnir** | Fjöldi hluta sem skref unnu þegar þau endurtóku sig yfir fylki. |
| **Villuboð** | Villuboðin þegar keyrslan mistókst. |
