**Keyrsluskrá keðju** sýnir allar keyrslur keðja, þær nýjustu efst. Hún er óbreytanleg og er upphafspunktur þegar rannsaka þarf tímasetta keðju. Veldu línu til að opna spjaldið [Upplýsingar um keðjukeyrslu](/help/orchestrator/playbook-instance-card/) með skrá hvers skrefs.

Stöðudálkurinn er litamerktur: keyrslur sem lauk eru hagstæðar, keyrslur sem mistókust óhagstæðar og keyrslur í gangi tvíræðar.

## Reitir

| Reitur | Lýsing |
| --- | --- |
| **Kóði keðju** | Keðjan sem var keyrð. |
| **Staða** | Staða keyrslunnar. |
| **Hafið** | Hvenær keyrslan hófst. |
| **Lokið** | Hvenær keyrslunni lauk. |
| **Heildartími** | Heildartími keyrslunnar. |
| **Skref keyrð** | Fjöldi skrefa sem voru keyrð. |
| **Skref mistókust** | Fjöldi skrefa sem mistókust. |
| **Hlutir unnir** | Heildarfjöldi hluta sem unnir voru í öllum ítrunum. |
| **Villuboð** | Villuboðin þegar keyrslan mistókst. |
