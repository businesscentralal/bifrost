Síðan **Bifröst mállíkan** sýnir öll skilgreind mállíkön fyrir Spjalla við Bifröst. Hvert mállíkan inniheldur kerfisleiðbeiningu, líkanaval og hæfnilista sem stýra hegðun gervigreindaspjallsins.

## Reitir

| Reitur | Lýsing |
| --- | --- |
| **Kóði** | Einkvæmt auðkenni mállíkansins. |
| **Lýsing** | Stutt lýsing á mállíkaninu. |
| **Líkan** | Gervigreindarlíkanið sem notað er. |

## Aðgerðir

| Aðgerð | Lýsing |
| --- | --- |
| **Nýtt** | Býr til nýtt mállíkan. |
| **Breyta** | Opnar [mállíkansspjaldið](/help/language-models/bifrost-lang-model-card/) til breytinga. |
