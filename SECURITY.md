# Security policy

This repository holds the public documentation site for the Bifröst family of
Business Central extensions. It contains no product source code and no
credentials.

## Reporting a vulnerability

Report suspected vulnerabilities in a Bifröst extension, or in this site, to
**bc@origo.is**. Do not open a public issue for a security report.

Include the app name and version, the environment (SaaS or on-premises), and
the steps needed to reproduce the problem. You will get an acknowledgement
within two business days.

## Scope

| In scope | Out of scope |
| --- | --- |
| Bifröst extensions published by Origo on Microsoft AppSource | Microsoft Dynamics 365 Business Central itself — report to Microsoft |
| This documentation site and its build workflows | Third-party services an app connects to (banks, storage providers, model providers) |
